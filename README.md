## Install

1. Open **`DeskRug.dmg`** — the disk image shows what to drag where.
2. Drag **Desk Rug** onto the **Applications** shortcut.
3. First launch: in **Applications**, right-click **Desk Rug → Open → Open**.
   The app is not notarized, so macOS warns once — this is expected.
   - macOS 15 and newer: if there is no **Open** button, go to
     **System Settings → Privacy & Security → Open Anyway**.
4. The icon appears in the menu bar. On the first **Sweep** / **Spread**, allow
   **Accessibility** and **Finder Automation** in the macOS prompts.
